# Week 02 과제: 기본 도형 배치 + 코드 장면 비교

## 과제 개요

Blender의 기본 뷰 조작과 Transform 기능을 활용하여 도형을 배치하고, 같은 장면을 코드로 다시 만들어 손 작업과 비교합니다.

## 제출 방법

- **제출처:** 본인 학생 페이지
- **형식:** 스크린샷 2장 + 비교표 + 한줄 코멘트
- **기한:** 다음 수업 전까지

## 과제 내용

### 스크린샷 1: 기본 도형 배치

- 기본 도형(Cube, Sphere, Cylinder, Cone, Torus 등)을 **5개 이상** 사용
- 자유롭게 배치하여 하나의 씬을 구성
- Transform(이동, 회전, 스케일)을 활용하여 다양한 크기와 위치로 배치
- Shading 모드는 Solid 또는 Material Preview 권장

### 스크린샷 2: 손 작업과 코드 장면 비교

- 수업의 「코드로 같은 장면 만들어 비교하기」 실습에서 렌더한 두 장을 나란히 놓은 이미지
- 코드는 Scripting 작업 공간에서 실행해도 되고, Blender MCP가 연결되어 있으면 MCP로 실행해도 됩니다
- 수업 페이지의 비교표(걸린 시간, 고친 횟수, 비율, 다시 만들기 쉬운 정도, 한 줄 소감)를 채워 함께 제출합니다

### 한줄 코멘트

- 작업 과정에서 느낀 점이나 어려웠던 부분을 한줄로 작성

## 평가 기준

| 항목 | 비율 | 설명 |
|------|------|------|
| 도구 활용 | 40% | Transform, 뷰 조작, 스크립트 실행을 올바르게 사용했는가 |
| 완성도 | 30% | 도형 배치가 의도를 가지고 구성되었는가 |
| 창의성 | 30% | 단순 배치를 넘어 재미있거나 독창적인 구성을 시도했는가 |

## 참고 사항

- Apply Transform(Ctrl + A)을 사용하여 Transform 값을 정리하는 것을 권장
- 첫 렌더는 셰이더 준비 때문에 1분 넘게 걸릴 수 있으니 미리 한 번 렌더해 둡니다
- 스크립트가 오류를 내면 Scripting 작업 공간의 콘솔 메시지를 확인하고 수업 중 질문
