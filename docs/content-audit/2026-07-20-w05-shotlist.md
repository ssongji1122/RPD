# Week 05 스텝 캡처 지시서

`2026-07-20-w05-pending-updates.md`의 잔여 항목 8(W05 실캡처 4장)을 채우기 위한 샷 리스트입니다.
제거된 플레이스홀더 4개를 대체하는 실캡처를 만듭니다.

## 배경

- 대상 스텝: 1(AI 3D 생성) · 3(Sculpt 기초) · 4(브러시 심화) · 5(Remesh와 마무리). 스텝 2(메쉬 정리)는 원래 이미지 없이 텍스트만으로 운영합니다.
- 기존 자산은 대부분 Blender 매뉴얼 텍스트 페이지 스크린샷이라 스텝 삽화로 쓰지 않습니다. 유일한 뷰포트 데모(`sculpt-grab.png` 상단)와 라벨이 어긋난 `sculpt-draw.png`(실제로는 VDM 데모)는 재사용하지 않고 신규 캡처로 대체합니다.
- 저작권: 유튜브 강의는 흐름·프레이밍 참고로만 씁니다. 프레임을 그대로 캡처해 발행하지 않습니다. 실제 이미지는 (a) 직접 조작한 Blender 뷰포트 캡처 또는 (b) Meshy 화면 캡처로 만듭니다. 둘 다 직접 만든 캡처라 출처 표기 부담이 없습니다.

## 전 샷 공통 규칙 (세트 일관성)

한 수업의 스텝 삽화는 같은 화면에서 나온 것처럼 보여야 합니다.

- **같은 모델을 관통**: 스텝 1에서 생성한 AI 로봇 메쉬를 3·4·5에서 계속 씁니다. 스텝마다 다른 오브젝트를 쓰면 흐름이 끊깁니다.
- **비율 16:9**: 스텝 카드 그리드가 가로형입니다. 캡처 후 1600×900(또는 1920×1080)로 맞춥니다.
- **Blender 기본 다크 테마**, N 패널·통계 오버레이는 그 스텝에서 필요한 것만 켭니다.
- **UI를 크게**: 학생이 버튼·패널 위치를 읽을 수 있어야 합니다. 4K 모니터면 Blender Resolution Scale을 올려 글자를 키운 뒤 캡처합니다.
- 파일명은 아래 표의 이름을 그대로 씁니다(기존 참조 경로와 맞물립니다).
- 저장 위치: `course-site/assets/images/week05/`. PNG.

## 샷 리스트

### 샷 1 — 스텝 1: AI 3D 생성 체험

- **파일명**: `ai-3d-generation.png`
- **소스**: Meshy 웹 UI (meshy.ai, 로그인 후 Text to 3D)
- **잡을 순간**: 프롬프트를 입력하고 생성이 끝나 결과 메쉬가 미리보기에 뜬 상태. 프롬프트 입력창과 생성 결과가 한 화면에 같이 보이는 프레임.
- **화면에 보여야 할 것**: (1) 프롬프트 입력 필드에 실제 문장(예: `small companion robot, round body, short arms, matte plastic, simple friendly face`), (2) 생성된 3D 로봇 프리뷰, (3) 다운로드/포맷 버튼 영역.
- **프레이밍**: Meshy 작업 화면 전체를 가로로. 좌측 프롬프트 · 우측 프리뷰가 다 들어오게.
- **주의**: 무료 플랜(월 100 크레딧)에서 생성 1회. 계정 이메일·결제 정보가 화면 구석에 노출되지 않게 크롭.
- **대체안**: Meshy가 막히면 Tripo(tripo3d.ai) Image to 3D 화면으로 동일 구도. 이때 파일명은 유지하되 캡션에 도구명 명시.

### 샷 2 — 스텝 3: Sculpt Mode 기초

- **파일명**: `sculpt-mode.png`
- **소스**: Blender 뷰포트 (스텝 1의 AI 로봇 임포트 후)
- **잡을 순간**: Sculpt Mode 진입 상태에서 Draw 또는 Grab 브러시로 표면을 한 번 밀어 브러시 원(커서 링)이 메쉬 위에 걸쳐 있는 프레임. 브러시가 "지금 작동 중"으로 읽혀야 합니다.
- **화면에 보여야 할 것**: (1) 상단 모드 드롭다운이 `Sculpt Mode`, (2) 좌측 브러시 툴바, (3) 메쉬 위 노란 브러시 커서 링, (4) 브러시가 남긴 표면 변형 흔적.
- **프레이밍**: 로봇 상반신 위주로 당겨서. 브러시 링이 또렷하게 보이는 각도.
- **참고**: 기존 `sculpt-grab.png` 상단의 "흰 덩어리+노란 링" 구도가 목표 레퍼런스입니다. 같은 느낌을 실제 로봇 모델로 재현.

### 샷 3 — 스텝 4: Sculpt 브러시 심화

- **파일명**: `sculpt-brushes.png`
- **소스**: Blender 뷰포트 (같은 로봇 모델, Sculpt Mode)
- **잡을 순간**: Clay Strips·Crease·Inflate 중 하나로 디테일을 넣은 직후. 세 브러시의 효과 차이가 보이면 가장 좋습니다.
- **화면에 보여야 할 것**: (1) 좌측 브러시 툴바에서 선택된 브러시가 하이라이트, (2) 브러시 이름이 상단/툴바에 보임, (3) 메쉬에 들어간 디테일(홈·볼륨).
- **프레이밍 (권장)**: 한 장에 브러시별 결과를 나란히 — 예: 같은 면에 Clay Strips로 볼륨 쌓은 곳 / Crease로 홈 판 곳 / Inflate로 부풀린 곳을 한 프레임에. 어려우면 대표 브러시(Clay Strips) 하나만 또렷하게.
- **주의**: 스텝 3과 브러시가 헷갈리지 않게, 이 샷은 "심화 브러시"임이 드러나는 툴바 상태를 넣습니다.

### 샷 4 — 스텝 5: Remesh와 마무리

- **파일명**: `remesh.png`
- **소스**: Blender 뷰포트 (같은 로봇 모델)
- **잡을 순간 (권장)**: Remesh 전/후 대비. 와이어프레임을 켜고, Remesh 적용 전 불균일한 토폴로지 → 적용 후 고른 격자가 대비되는 구도.
- **화면에 보여야 할 것**: (1) 와이어프레임이 보이는 뷰포트(Z → Wireframe 또는 오버레이), (2) Remesh 전이면 삼각형이 뒤엉킨 상태 / 후면 균일한 사각 격자, (3) 가능하면 Remesh 패널(Voxel Size)이 함께.
- **프레이밍**: 전/후를 한 프레임에 좌우로 두면 이해가 가장 빠릅니다. 단일 프레임이면 Remesh 적용 후 균일 격자 상태.
- **참고**: 스텝 본문이 "메쉬를 다시 고르게 나눠주는 리셋 버튼"이라고 설명하므로, 삽화도 "고르게 나뉜 격자"가 핵심 메시지입니다.

## 캡처 후 반영 절차

1. 4장을 `course-site/assets/images/week05/`에 위 파일명으로 저장(16:9, PNG).
2. `site-data.json`의 week05 각 스텝 `image` 필드를 복원하고, 병행해 `overrides.json`에도 동일 반영(양쪽을 맞춰야 notion-sync 후에도 유지 — pending-updates 문서의 sync 레이어 주의 참조).
3. `python3 tools/content_pipeline.py check && build`로 재생성, `web`에서 `npm run build` 스모크.
4. 라이브 W05에서 4장이 뜨는지 확인.
5. lecture-note 본문의 이미지(`![...](...)`)는 build가 AUTO:CURRICULUM-SYNC 블록에서 자동 갱신하므로 수동 편집하지 않습니다.

샷 리스트의 각 "잡을 순간"을 어떤 앵글·타이밍으로 잡을지 감을 잡는 용도로만 씁니다. 검색어 예: `Blender AI 3D Meshy sculpt cleanup tutorial`, `Blender sculpt mode beginner brushes`, `Blender voxel remesh sculpt`. 영상 프레임을 캡처해 넣지 않습니다.
