## 지금 수업과의 관계

Week 02는 기본 도형(Cube·Sphere·Cylinder·Cone·Torus)을 손으로 배치하는 실습과 Blender MCP 연결 테스트를 함께 다룹니다. 두 활동이 따로 진행되어, 학생은 MCP가 연결되었다는 스크린샷만 내고 AI가 만든 장면과 자기가 만든 장면을 비교할 기회가 없습니다. 강사 노트에도 MCP 연결이 막히면 시연으로 대체한다고 적혀 있어, MCP 없이도 진행할 수 있는 대안이 필요합니다.

## 보강안

### 실습 흐름 (15분, 「기본 도형으로 나만의 장면 만들기」 바로 뒤)

1. 손으로 만든 장면을 `F12`로 한 장 렌더해 저장합니다.
2. Claude에게 같은 장면을 Blender 파이썬 스크립트로 만들어 달라고 요청합니다. 프롬프트 예시는 아래에 있습니다.
3. Blender의 Scripting 작업 공간에 스크립트를 붙여 넣고 실행합니다. MCP가 연결된 학생은 MCP로 바로 실행해도 됩니다.
4. 같은 해상도로 한 장 더 렌더하고, 두 장을 나란히 놓고 비교표를 채웁니다.

Scripting 작업 공간에서 실행하는 방식은 MCP 설치 여부와 관계없이 모든 학생이 할 수 있습니다. MCP 연결이 막힌 학생도 같은 실습을 마칠 수 있으므로 강사 노트의 시간 부족 대응과도 맞습니다.

### 학생용 프롬프트 예시

```
Blender 5.0에서 실행할 파이썬 스크립트를 써 줘.
- 기존 오브젝트를 모두 지우고 시작해.
- 기본 도형만 써서 눈사람을 만들어 줘: Sphere 3개(몸통·가슴·머리), Cone 1개(코), Cylinder 1개(모자), 바닥 Plane 1개.
- 카메라와 Sun 조명을 하나씩 넣고, 카메라가 눈사람 전체를 비추게 해 줘.
- 렌더 해상도는 960×540으로 맞춰 줘.
- 숫자(크기·위치)는 맨 위에 이름을 붙여 모아 둬서 내가 바꿔 볼 수 있게 해 줘.
```

### 비교표 (과제에 함께 제출)

| 항목 | 손으로 만든 장면 | 코드로 만든 장면 |
|---|---|---|
| 걸린 시간 | | |
| 원하는 모양이 나올 때까지 고친 횟수 | | |
| 비율이 마음에 드는가 | | |
| 숫자 하나를 바꿔 다시 만들기가 쉬운가 | | |
| 한 줄 소감 | | |

비교 기준에서 "어느 쪽이 더 낫다"를 정답으로 두지 않습니다. 이 실습의 목표는 G·R·S로 만든 결과가 코드에서는 위치·크기·회전 숫자로 표현된다는 점을 학생이 직접 보는 것입니다. Week 02의 Transform 학습 목표와 이어집니다.

### 강사용 기준 스크립트

`weeks/week02-blender-basics/examples/snowman_scene.py`를 함께 추가했습니다. 프롬프트 예시와 같은 조건으로 눈사람 장면을 만들고, 터미널에서 실행하면 PNG 한 장을 렌더합니다. Claude가 만든 스크립트가 오류를 낼 때 비교해 볼 정답 예시로 씁니다.

```
blender --background --python weeks/week02-blender-basics/examples/snowman_scene.py -- <출력 PNG 경로>
```

검증: 2026-10-25 이 맥의 Blender 5.0.1에서 `--background --factory-startup`으로 실행해 960×540 PNG가 저장되는 것을 확인했습니다. 첫 실행은 셰이더 준비 때문에 약 79초, 두 번째 실행은 약 3초가 걸렸습니다. 수업 PC에서 처음 렌더할 때도 1분 넘게 걸릴 수 있으므로 시연 전에 한 번 미리 렌더해 둡니다.

## 넣지 않는 것

원문 영상의 360장 애니메이션 렌더와 FFmpeg 연결은 Week 02에 넣지 않습니다. 애니메이션은 Week 10(Animation 기초), 렌더 설정과 영상 출력은 Week 13(AI 영상·렌더링·MCP) 범위입니다. Week 13 보강 때 같은 기준 스크립트에 키프레임 몇 개를 더해 짧은 렌더 비교로 확장할 수 있습니다.
