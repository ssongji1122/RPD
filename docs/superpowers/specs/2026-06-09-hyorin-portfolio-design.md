## 1. 개요

- **What**: 정효린 학생의 인하대 Blender 수업 15주 결과물을, 캐릭터 **'보물이'** 를 관통선으로 하는 **스크롤 내러티브 포트폴리오 단일 페이지**로 제작.
- **주체(목소리)**: 정효린 본인 — **1인칭**.
- **독자**: 채용담당자, 특히 **기업 홍보실 / 3D·모션·AI 크리에이티브** 직무.
- **Why**: 취업용. "0 → AI 기반 3D 워크플로 완성"까지 15주 성장과, 실제 브랜드(삼성화재) 연계 기획력을 30초 안에 증명.
- **핵심 무기**: 흩어진 과제가 아니라, W1 컨셉 → W13 완성까지 **단일 캐릭터를 관통하는 스토리**가 이미 존재함.

## 2. 목표 & 비목표

**목표**
- 흐름(W1→W13)을 스크롤로 체감하게 한다. ("흐름대로" — 사용자가 두 번 강조한 핵심 요구)
- Dribbble의 경쾌한 밝은 멀티컬러 베이토 무드를 가져온다.
- 작품(3D 렌더·애니메이션·AI 영상)이 카드 안에서 주인공이 되게 한다.
- 채용담당자가 스크롤만으로 "이 사람이 무엇을 할 수 있나"를 파악한다.

**비목표 (YAGNI)**
- 재사용 템플릿화 / CMS / 백엔드 — 이 학생 1명 전용 standalone.
- 다국어, 로그인.
- W7·W14·W15 미제출분 억지로 채우기 — 완성된 W1→W13 arc만 전시.
- RPD 기존 다크+민트 디자인 시스템 준수 — standalone이라 무관, **독립 토큰** 사용.

## 3. 콘텐츠 소스 & 자산 파이프라인 (리스크 1순위)

- **소스**: Notion 페이지(정효린 개인 페이지). 이미지 약 51장 + 영상/첨부 다수 + Mixboard 외부 링크 6개.
- **확인된 문제**: 이미지 51개 S3 signed URL **전부 403 만료** 검증됨. 직접 핫링크 불가. GitHub Pages 배포 시 전부 깨진다.
- **확보 전략 (구현 1단계 — 본 문서와 별개로 먼저 실행, 안 되면 전체 정지)**:
  - **경로 A (추천·자동)**: Notion API로 페이지 **fresh re-fetch** → 새 signed URL(유효 ~1시간) → 즉시 스크립트로 일괄 다운로드 → `assets/`에 정리 → commit.
  - **경로 B (수동·안전)**: 정효린/사용자가 Notion에서 **Export**(Markdown & CSV, include files 체크) → zip의 원본 이미지·영상 → repo 정리. 원본 화질이 중요하면 이 경로.
- **영상(.mp4)**: Notion 첨부 영상을 다운로드해 **self-host**(확정). 다운로드 시 용량 확인 → 과대 시 압축. (W8·W10·W11·W12·W13 영상 포함)
- **.blend 파일**: 웹 자산 아님 → 다운로드 링크로만 제공하거나 생략. **절대 임베드 금지.**
- **큐레이션 원칙**: 마일스톤당 **베스트 2~3컷만**. 51장 전부 덤프 금지 — 채용담당자는 양이 아니라 정점을 본다.

## 4. 정보구조(IA) & 페이지 골격

단일 페이지, 세로 스크롤.

```
[0] (데스크톱) 좌측 고정 미니 세로네비 — Intro / Works / Tools / Contact
[1] 히어로 (베이토, ~1뷰포트)
     ├ About 카드 (인물 또는 보물이 키비주얼 + "Im, 정효린" + 한 줄 소개 + 이메일)
     ├ 초대형 타이포 헤드라인
     ├ 통계 타일 (15 Weeks / 7 Tools / 5 Renders / 1 Character)
     └ 대표 영상 카드 (W13 Kling AI)
[2] 스크롤 챕터 (W1→W13, 6 챕터)
     ├ Ch1 컨셉 — 보물이 기획 (W1, Mixboard)
     ├ Ch2 기초 — Blender 모델링 (W2~4)
     ├ Ch3 AI 3D — Hyper3D 생성 (W5)
     ├ Ch4 재질·빛 — 셰이더·라이팅 (W6, W9)
     ├ Ch5 움직임 — 애니메이션·리깅·Mixamo (W10~12)
     └ Ch6 완성 — 렌더 + AI 영상·음악 (W13)
[3] 클로징 — 한 줄 선언 + 연락처 CTA(이메일)
```

각 챕터 = 베이토 무드 미니 그리드(큰 작품 카드 + 보조 샷 + 캡션/숫자 + 코너 브래킷).

## 6. 디자인 시스템

RPD `DESIGN.md`와 **독립된 별도 토큰**(`portfolio-tokens.css`). 밝은 멀티컬러 베이토.

**팔레트** (Dribbble 추출 근사값 — 구현 시 정밀화)

| 토큰 | 근사값 | 용도 |
|---|---|---|
| `--pf-bg` | `#ECECEC` | 페이지 배경(밝은 회색) |
| `--pf-card` | `#FFFFFF` | 기본 카드 |
| `--pf-violet` | `#7B6EF6` | About 카드, primary |
| `--pf-mint` | `#A8E0D8` | 통계 타일(Projects 류) |
| `--pf-yellow` | `#FBC95E` | 강조 카드 |
| `--pf-ink` | `#111111` | 블랙 카드, 헤드라인 |
| `--pf-pink` | `#EBA6E0` | 인물 원 배경 포인트 |
| `--pf-sky` | `#7EC8E3` | 정효린 시그니처(보물이 하늘색) 액센트 |
| `--pf-text` | `#1A1A1A` / `--pf-muted` `#6B6B6B` | 텍스트 |

원칙: 멀티컬러는 **카드 배경**으로만. 카드 위 텍스트는 고대비(WCAG AA) 유지.

**타이포** (방향만; 정확 스케일은 구현 시 `wiki/references/design/03_typography.md` 따라 확정)
- 헤드라인(영문): **Space Grotesk** ExtraBold (확정, 무료·지오메트릭 그로테스크).
- 한글: **Pretendard** (700~900 디스플레이, 400~500 본문). `word-break: keep-all`, 숫자 `font-variant-numeric: tabular-nums`.
- 모듈러 스케일 1.20~1.25, hero는 초대형 `clamp()`.
- 영문 디스플레이 + 한글 혼용 시 한글 폴백 weight 보정(600+).

**컴포넌트**
- `BentoCard` — 라운드 20~28px, 컬러 배경, 패딩, 코너 브래킷(ㄱ자) 옵션.
- `StatTile` — 큰 숫자(tabular) + 라벨, 단색 배경.
- `MediaCard` — 이미지/영상 full-bleed 라운드 클립, 영상은 플레이 버튼 오버레이.
- `SealBadge` — 원형 회전 텍스트 도장("2026 · PORTFOLIO").
- `SideNav` — 세로 텍스트 네비(데스크톱 전용).
- `CornerBracket` — 장식 ㄱ자(Dribbble 시그니처).

## 7. 레이아웃 & 반응형

- **데스크톱**: 베이토 그리드(12컬럼 기준). 히어로 비대칭(좌 About 세로 카드 ~1/3, 우 헤드라인+통계+영상 ~2/3).
- **태블릿(~900px)**: 베이토 2~3열로 재배치.
- **모바일(~600px)**: 1열 세로 스택, 카드 풀폭, 세로 네비 숨김.
- 브레이크포인트 3단계. 챕터는 과한 가로 스크롤·스크롤재킹 금지(접근성).

## 8. 모션 & 인터랙션

- 스크롤 인뷰 페이드/슬라이드업 (subtle). `prefers-reduced-motion` 존중.
- 카드 hover: 살짝 lift / scale(1.02) + 코너 브래킷 강조.
- 영상: 클릭 재생(**자동재생 금지** — 데이터·접근성).
- 과한 패럴랙스 금지.

## 9. 카피 전략

- **1인칭 한국어**, 군더더기 없는 톤. 마케팅 과장·가짜 지표 금지(실제 결과물로 증명).
- 학생 소감 인용을 **성장 증거**로 배치: W2 "처음 접해봤다" → W13 "AI 영상·음악으로 완성".
- 영문 초대형 헤드라인 + 한글 본문 혼용.
- 공식 도구는 하단에 출처 표기(Blender, Kling AI, Suno AI 등) — 글로벌 규칙(공식 링크 mention).

## 10. 기술 스택 & 구현 접근

- **스택**: 바닐라 HTML/CSS/JS (프레임워크 없음). RPD 관례와 같되 **토큰은 독립**.
- **툴체인**: generate-then-refine.
  1. **stitch / claude design** 으로 베이토 비주얼·컬러 배치·통계 타일 시안을 빠르게 탐색.
  2. 확정안을 **바닐라 HTML/CSS로 hand-build** — 자산 통합·반응형·접근성을 정밀 제어(생성물 그대로 쓰지 않음).
- **파일 구조(안)**: `portfolio/hyorin/index.html` · `portfolio/hyorin/styles/*.css` · `portfolio/hyorin/assets/`.
- **호스팅**: GitHub Pages, **RPD repo 서브패스 `portfolio/hyorin/`** (확정).

## 11. 프라이버시 & 동의

- 이름: **유지**(취업 포트폴리오, 채용담당자가 필요).
- 학번(00000000): **비공개**(내부 admin 데이터, 채용 가치 0).
- **발행 전 게이트**: 정효린 본인에게 (a) 공개 동의, (b) 이미지·인용 사용 동의 — 1줄 확인 후 배포.
- 삼성화재 캐릭터: **수업 과제(가상 기획)** 임을 명시. 실제 삼성화재 로고·자산 무단 사용 주의.

## 12. 접근성

- 멀티컬러 카드 위 텍스트 대비 WCAG AA 충족.
- 키보드 포커스, `alt` 텍스트, `prefers-reduced-motion`, 영상 캡션(가능 시).
- 구현 후 RPD `rpd-a11y-audit` 스킬 적용.

## 13. 성공 기준 & QA

- 채용담당자가 스크롤만으로 W1→W13 흐름·역량을 파악한다.
- 모든 자산 로컬 호스팅 — 만료 링크 0, 깨진 이미지·영상 0.
- 반응형 3 브레이크포인트 정상.
- Lighthouse 접근성·성능 90+ 목표.

## 14. 확정 사항 (사용자 리뷰 통과, 2026-06-09)

1. 통계 타일: `15 Weeks · 7 Tools · 5 Renders · 1 Character`.
2. 영상: Notion 첨부 영상 다운로드 → self-host. 용량은 다운로드 시 확인, 과대 시 압축.
3. 인물 사진: **미사용**(없음) → About 카드는 보물이 키비주얼로 대체.
4. 호스팅: RPD repo 서브패스 `portfolio/hyorin/`, GitHub Pages.
5. 헤드라인 폰트: Space Grotesk ExtraBold.
6. 삼성화재: "학생 수업 과제 / 비공식 컨셉" 명시, 실제 로고·자산 미사용.

## 15. 구현 단계 미리보기 (writing-plans에서 상세화)

1. 자산 확보(재fetch+다운로드 또는 export) + 큐레이션.
2. 디자인 토큰·컴포넌트 확정(stitch/claude 탐색 → 토큰 고정).
3. 히어로 베이토 구현.
4. 챕터 스크롤 구현 + 콘텐츠/카피.
5. 반응형 · 모션 · 접근성.
6. QA + 동의 게이트 + 배포.
