## 핵심 토큰

| 토큰 | HEX | 용도 |
|------|-----|------|
| `--c-bg` | `#F6F3EE` | 라이트 기본 배경 |
| `--c-bg-2` | `#ECE6DC` | 보조 배경 |
| `--c-bg-dark` | `#1B1718` | 다크 인버스 |
| `--c-ink` | `#1B1718` | 본문 텍스트 |
| `--c-ink-2` | `#514B47` | 보조 텍스트 |
| `--c-ink-3` | `#8F8982` | 힌트·캡션 |
| `--c-line` | `#E3DCD2` | 구분선 |
| `--c-accent` | `#00BFA5` | 링크·CTA (다크 인버스 `#2DD4BF`) |
| `--c-eucalyptus` | `#3F706D` | 큰 숫자·서브 |
| `--c-dusty` | `#8F8982` | 보조 강조 |
| `--c-soot` | `#1B1718` | 깊은 앵커 |

> 토큰명과 HEX는 디자인 토큰 파일(tokens.css 등)과 동기화한다.

## 사용 원칙

- 기본 화면은 배경 + 잉크로만 구성한다. 단조로워 보일 정도가 정답이다.
- accent는 링크·CTA에 한정한다. 본문 강조용으로 남발하면 톤이 깨진다.
- 다크 화면은 예외적으로만 쓴다. 기본은 라이트.
