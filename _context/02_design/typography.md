# 타이포그래피

## 폰트 스택

| 역할 | 폰트 |
|------|------|
| Display / Heading (영문) | Cormorant Garamond |
| Heading 한글 | Nanum Myeongjo |
| Body | Pretendard |
| Mono / Meta / 라벨 | JetBrains Mono |

**Modular Scale:** 1.20 (Minor Third)

## 사용 원칙 (기본값 — 프로젝트에 맞게 조정)

- 한글 본문 줄바꿈은 `word-break: keep-all`.
- 한글 본문 `line-height: 1.7`, `letter-spacing: -0.01em`.
- 헤딩에 시스템 폰트(-apple-system만) 사용 금지 — 폰트를 명시 지정.
