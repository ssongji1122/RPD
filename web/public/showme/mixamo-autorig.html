Mixamo는 Adobe가 무료로 운영하는 웹 서비스(mixamo.com)입니다. 두 가지 기능을 제공합니다. 하나는 자동 리깅이고, 다른 하나는 2500개 이상의 모션 라이브러리 제공입니다.

자동 리깅은 업로드한 메쉬 위에 5개 마커(Chin·Wrists·Elbows·Knees·Groin)만 찍으면 AI가 뼈대 위치를 계산해 Armature와 Weight를 자동으로 생성합니다. 10~30초면 결과를 다운로드할 수 있습니다.

전체 워크플로는 Blender → FBX export → Mixamo 업로드 → 마커 5개 배치 → 자동 리깅 + FBX 다운로드 → Blender 재import의 5단계입니다.

  1. 1 메쉬 정리 및 T-Pose 확인 후 FBX export Ctrl+J 여러 파츠는 합치고, Apply All Transforms 후 export
  2. 2 mixamo.com에 Adobe 계정으로 로그인 후 Upload Character
  3. 3 5개 마커 배치 Chin(턱), Wrists(양 손목), Elbows(양 팔꿈치), Knees(양 무릎), Groin(사타구니)
  4. 4 Next 클릭 후 자동 리깅 결과 확인, FBX 다운로드 Skeleton LOD 65본, Format FBX Binary, With Skin 권장
  5. 5 Blender에 FBX import File > Import > FBX (.fbx) 본 이름은 mixamorig_* 형식으로 생성됩니다

언제 쓰나요

빠른 캐릭터 애니메이션이 필요한 프로젝트, 즉시 사용 가능한 모션 라이브러리가 필요할 때, Blender에서 직접 본 배치·웨이트 페인트가 부담스러울 때 씁니다. 게임 프로토타입, 학습용 캐릭터, 데모 영상 제작에 적합합니다.

4족 동물·로봇·비인체형 캐릭터에는 거의 실패하므로 사용하지 않는 것이 좋습니다. 손가락 개별 컨트롤이 꼭 필요한 경우나 오리지널 모션이 핵심인 시네마틱 작업에도 라이브러리만으로는 한계가 있습니다.

흔한 실수

- 캐릭터 자세가 A-Pose이거나 손이 가슴에 붙어 있으면 마커가 잡히지 않습니다. 반드시 T-Pose(팔을 좌우로 펼친 자세)로 올려야 합니다. - 메쉬가 여러 파츠로 나뉘어 있으면 업로드 전에 Ctrl+J로 단일 오브젝트로 합쳐야 합니다. Mixamo는 단일 메쉬만 안정적으로 처리합니다. - Blender로 받아온 다음 Armature가 보이지 않을 수 있습니다. Outliner에서 Armature 오브젝트를 펼쳐 Display As → Stick 또는 Octahedral로 바꾸면 뼈대가 보입니다.
