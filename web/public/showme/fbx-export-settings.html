FBX(Filmbox)는 Blender 모델을 Mixamo·AccuRIG·Unity·Unreal 등으로 보내는 표준 3D 데이터 교환 포맷입니다. Mesh, Material, Armature, Animation을 하나의 파일에 묶어 다른 소프트웨어로 옮깁니다.

Export 직전에 사전 준비 세 가지를 반드시 끝내야 합니다. 첫째, Ctrl+J로 모든 파츠를 단일 메쉬로 합칩니다. 둘째, Ctrl+A > All Transforms로 Scale·Rotation을 강제 적용합니다. 셋째, Mixamo 업로드 시에는 기존 Armature를 미리 제거합니다.

Export 옵션에서 핵심은 Transform 섹션입니다. Apply Scalings는 All Local, Forward는 -Z Forward, Up은 Y Up으로 설정해야 Mixamo·AccuRIG가 T-Pose를 올바르게 인식합니다.

  1. 1 전체 선택 후 단일 메쉬로 합치기 A A로 전체 선택 후 Ctrl+J
  2. 2 All Transforms 적용 Ctrl+A Apply > All Transforms
  3. 3 FBX Export 메뉴 진입 File > Export > FBX (.fbx)
  4. 4 Transform 옵션 설정 Apply Scalings: All Local / Forward: -Z Forward / Up: Y Up
  5. 5 Geometry > Apply Modifiers 체크
  6. 6 Armature > Add Leaf Bones 체크 해제 확인 후 Export

언제 쓰나요

Blender 캐릭터를 Mixamo나 AccuRIG로 보내 자동 리깅을 받을 때 씁니다. Unity·Unreal 게임 엔진으로 내보낼 때도 FBX가 가장 안정적인 경로입니다. Substance Painter·Marvelous Designer 등 다른 3D 소프트웨어와 데이터를 교환할 때도 사용합니다.

흔한 실수

- Apply Transform 누락이 가장 흔한 실수입니다. Ctrl+A > All Transforms를 안 하면 Mixamo에서 캐릭터가 1cm로 줄거나 100m로 거대해집니다. - 축 방향이 틀리면 캐릭터가 옆을 보거나 누워서 import됩니다. Blender 기본값(Y Forward, Z Up)이 아니라 -Z Forward, Y Up으로 설정해야 합니다. - Add Leaf Bones를 켜면 손끝·발끝에 더미 본이 추가돼 Mixamo 자동 리깅이 혼란을 겪을 수 있습니다. 끄는 것이 안전합니다. - Apply Modifiers를 체크하지 않으면 Subdivision Surface 등이 적용되지 않은 저폴리 메쉬로 export됩니다.
