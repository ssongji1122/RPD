Rigify는 Blender에 내장된 자동 리깅 애드온입니다. AI가 아니라, 미리 정해 놓은 뼈 템플릿(메타리그)을 기반으로 IK·FK·Pole·Tweak 컨트롤 본을 한 번에 만들어 줍니다.

작업은 두 단계로 이루어져 있습니다. 먼저 Meta-Rig를 씬에 추가해 캐릭터 비율에 맞게 본 위치를 조정하고, 그 다음 Generate Rig 버튼을 눌러 완전한 컨트롤 리그를 생성합니다. 메타리그는 비율 맞추기용이고, 생성된 리그가 실제 애니메이션에 쓰이는 본입니다.

지원하는 메타리그 종류로는 Human(사람형 표준), Basic(팔·다리·꼬리 단순), Animals(Cat·Wolf·Bird 등)가 있습니다.

  1. 1 Rigify Add-on 활성화 Edit > Preferences > Add-ons > 'Rigify' 검색 후 체크박스 활성화
  2. 2 Meta-Rig 추가 Shift+A Add > Armature > Rigify Meta Rigs > Human (Meta-Rig)
  3. 3 Edit Mode에서 캐릭터 비율에 맞게 각 본의 위치 조정 Tab 좌우 대칭은 X-Axis Mirror 옵션을 켜면 편리합니다
  4. 4 Generate Rig 실행 Properties > Armature > Rigify Buttons > Generate Rig 별도의 새 아마추어 오브젝트(rig)가 생성되며 메타리그는 그대로 남습니다
  5. 5 메쉬를 리그에 연결 Ctrl+P 메쉬 먼저 선택 → Shift+클릭으로 리그 추가 선택 → With Automatic Weights

언제 쓰나요

인체형 캐릭터나 동물형 캐릭터에 IK·FK 전환이 포함된 풍부한 컨트롤 리그가 필요할 때 씁니다. 직접 수동으로 만들면 며칠 걸리는 컨트롤 본 세트를 몇 초 만에 완성해 줍니다.

반면, 관절 구조가 특이한 로봇·기계, 사물·식물, 표준 인체 비율을 크게 벗어난 캐릭터에는 적합하지 않습니다. 이런 경우에는 수동 리깅이 결과가 더 깔끔합니다.

흔한 실수

- Generate Rig를 누르기 전에 메타리그의 관절 위치를 꼼꼼히 맞춰야 합니다. 비율이 어긋난 채 생성하면 결과 리그를 수정하는 것이 처음부터 다시 만드는 것보다 더 오래 걸립니다. - 메쉬를 리그에 연결할 때 선택 순서가 중요합니다. 메쉬를 먼저 선택하고 Shift+클릭으로 리그를 추가 선택(Active)한 뒤 Ctrl+P → With Automatic Weights를 선택해야 합니다. 순서가 바뀌면 부모-자식 관계가 거꾸로 잡힙니다. - Rigify는 기본 내장이지만 처음엔 꺼져 있습니다. Edit > Preferences > Add-ons에서 활성화해야 합니다.
