본끼리 부모-자식 관계를 맺을 때 두 가지 방식이 있습니다. 어떤 방식을 선택하느냐에 따라 자식 본의 위치와 움직임이 달라집니다.

Connected는 자식 본의 Head가 부모 본의 Tail에 강제로 붙어 두 본이 한 직선 체인을 이룹니다. 팔, 척추, 손가락처럼 관절이 항상 붙어 있어야 하는 부위에 씁니다.

Free (Keep Offset)는 계층 관계는 유지하지만 자식 본의 위치는 원래 자리 그대로 둡니다. 부모와 자식 사이에 빈틈이 있어도 됩니다. 쇄골과 상완처럼 회전축이 어긋난 부위나 컨트롤 본에 씁니다.

  1. 1 Edit Mode에서 자식 본을 먼저 선택 모드는 반드시 Edit Mode여야 합니다
  2. 2 부모 본을 Shift+클릭으로 추가 선택 (부모가 Active)
  3. 3 부모 설정 메뉴 열기 Ctrl+P
  4. 4 연결 방식 선택 직선 체인이면 Connected, 두 본이 떨어져 있으면 Keep Offset
  5. 5 부모 관계 해제가 필요할 때 Alt+P Clear Parent는 완전 해제, Disconnect Bone은 Connected만 해제

언제 쓰나요

두 본이 한 직선 체인을 이루고 관절이 절대 떨어지면 안 된다면 Connected를 선택합니다. 대표적으로 팔 체인(상완→전완→손), 척추, 손가락 마디, 꼬리가 해당됩니다.

두 본의 시작점이 서로 떨어져 있거나 독립적으로 회전해야 한다면 Free(Keep Offset)를 선택합니다. 쇄골→상완, 골반→허벅지, IK Target·Pole Target 같은 컨트롤 본, 로봇 파츠 등이 여기에 해당합니다.

흔한 실수

- 가장 흔한 실수는 쇄골을 상완의 부모로 Connected로 묶는 것입니다. 그러면 상완 Head가 쇄골 Tail로 끌려가서 어깨 위치가 망가집니다. 두 본이 떨어져 있으면 무조건 Keep Offset입니다. - 선택 순서를 반드시 지켜야 합니다. 자식 본을 먼저 선택하고, 마지막에 부모 본을 Shift로 추가 선택한 뒤 Ctrl+P를 눌러야 합니다. 순서가 바뀌면 부모-자식이 거꾸로 잡힙니다. - Connected 상태에서는 자식 본의 Head를 G로 따로 옮길 수 없습니다. 위치를 바꾸려면 먼저 Alt+P → Disconnect Bone으로 분리해야 합니다.
