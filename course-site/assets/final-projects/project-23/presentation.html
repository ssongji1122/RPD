01 · Overview

한국의 전통을
안드로이드에 입히다

묘한(猫韓)은 고양이 묘(猫)와 한국의 한(韓)이 합쳐진 이름이자, 전통과 미래를 잇는 '묘한' 능력을 가졌다는 중의적 의미다. 조선 도포와 갓을 입은 4등신 고양이 안드로이드 — 쥐를 잡는 것보다 정자 마루에서 낮잠 자는 것을 더 좋아하는 로봇.

힙합 스텝을 밟을 때 잊혀진 한국의 미(美)가 선명하게 복원된다는 설정. 차가운 첨단 기술의 '로봇', 따뜻한 '전통 한복', 영리함의 '고양이' — 세 가지 이질적인 키워드의 융합.

전통 × 미래 한국적 SF designer toy 고양이 로봇 4등신 피규어 조선 안드로이드

컨셉 키워드

cute black cat robot figure · designer toy style
large helmet head with cat ears · round face
soft rounded shapes · smaller glowing LED eyes
한복을 입은 검은 고양이 로봇

04 · Reflection

블렌더를 처음 열던 날부터
묘한이 춤을 추기까지

배운 것

Blender 전반 워크플로를 처음부터 익혔다. AI가 만들어준 메쉬를 손으로 다듬고, Python 스크립트로 달빛을 설계하고, Mixamo로 힙합 댄스를 입히는 과정에서 '툴을 다루는 것'과 '표현을 설계하는 것'이 다르다는 걸 배웠다.

아쉬운 것

UV 언래핑(Week 07)이 미완으로 남았다. 텍스처 페인팅의 가능성을 더 탐구하지 못한 것, 그리고 중간과 기말 사이 일부 과정을 더 촘촘히 기록하지 못한 것이 남는다.
